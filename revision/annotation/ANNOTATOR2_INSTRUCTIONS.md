# Independent relevance labels for the 50 retrieval questions (second annotator)

**Purpose.** The reviewers asked for a second, independent annotation of the retrieval ground truth so that we can report inter-annotator agreement. Please work **independently**. Do not look at anyone else's labels, and do not discuss the questions with anyone until you have finished.

**Files**
- `retrieval_relevance_annotator2.xlsx`: sheet *Questions*, 50 rows, one per student question.
- `All_Lectures_Slides.pdf`: all 23 lectures in one file. Use the bookmarks (Lecture → Slide) to move around. Every page shows a red label "Lecture N - Slide k" in its top-left corner.

**Task.** For each question, find the slides in the lecture deck that a student would need in order to answer it, and enter them in the column *Relevant slides*.
- A slide is **relevant** if it contains information needed to answer the question: it explains the concept, states the formula or mechanism, or works the example.
- A slide is **not relevant** if it only mentions the topic in passing, is about something else, or repeats a definition without the part the question asks about.
- You may choose any number of slides, from any lecture. A question can have one relevant slide or several.
- Write each slide as `lecture-slide`, separated by semicolons. Example: `13-27; 13-29; 14-6`.

**Rules**
- Use only the slide deck. Do not use ALIVE, AI tools, or web search.
- Record roughly how many minutes each question took (column *Minutes spent*, whole minutes, e.g. `2`).
- Do not change the Q or Question columns.

**Time.** About 1.5–2.5 hours.

**Return.** Save the sheet as `retrieval_relevance_annotator2_<initials>.xlsx` and send it back.
